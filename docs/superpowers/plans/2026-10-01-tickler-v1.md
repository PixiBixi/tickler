# Tickler V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Tickler V1: a SQLite-backed reminder store with a `tickler` CLI for Claude Code and a native macOS menu bar app with notifications, session resume and calendar sync.

**Architecture:** SwiftPM package with a `TicklerCore` library (model, store, parsing, pure planners, resumer), a `TicklerCLI` library plus a thin `tickler` executable, and a SwiftUI app generated by XcodeGen that links `TicklerCore`. The SQLite file is the only source of truth; writers post a Darwin notification, the app reconciles.

**Tech Stack:** Swift 6.3 toolchain, macOS 14+, GRDB.swift 7, swift-argument-parser 1.x, Swift Testing, SwiftUI, UserNotifications, EventKit, XcodeGen, SwiftLint, SwiftFormat, lefthook, GitHub Actions, Renovate.

**Spec:** `docs/superpowers/specs/2026-10-01-tickler-design.md`

**Format note:** the owner is asleep and pre-approved execution. Core tasks are implemented by the plan author directly, so steps list the tests and interfaces precisely and leave code to the implementation commits instead of duplicating it here.

## Global Constraints

- Deployment target: macOS 14.0. Bundle id `io.github.pixibixi.tickler`. URL scheme `tickler`.
- Database: `~/Library/Application Support/Tickler/tickler.sqlite`, overridable with `TICKLER_DB` (tests, CLI).
- Darwin notification name: `io.github.pixibixi.tickler.changed`.
- Only two third-party dependencies: GRDB.swift and swift-argument-parser.
- CLI strict date format `YYYY-MM-DD HH:MM`, local time. Exit codes 0, 1 runtime, 2 usage, 3 not found. English only.
- App strings in a String Catalog, English development language plus French.
- Code comments 1 to 3 lines, no em dash, en dash or bullet characters anywhere.
- Conventional Commits, one scope per commit, signed, identity `PixiBixi@users.noreply.github.com`.
- No push, no remote: the repo stays local until the owner decides.

## Review Focus

- A reminder due while the Mac sleeps: on wake it must be notified once, not zero and not twice (catch-up plus pending request firing). Pinned in Task 5 planner tests: catch-up excludes reminders whose pending request still exists.
- Snooze of a reminder whose notification was already delivered: the old delivered banner must go and the new request must replace the old id. Pinned in Task 5 (`<id>@<epoch>` identifiers differ, planner removes the stale one).
- A bare time typed after it passed today ("9h" at 10:45) must mean tomorrow, never a past date. Pinned in Task 4.
- Notes with trailing punctuation around URLs (`(https://...)`, `https://....,`) must not produce broken links. Pinned in Task 3.
- Two writers at once (CLI while the app writes): WAL plus GRDB busy timeout, no lost write. Pinned in Task 2 with two `DatabasePool` instances on the same file.

### Task 2: Model and store

**Files:** `Sources/TicklerCore/Model/{Reminder,ReminderLink,ReminderID}.swift`, `Sources/TicklerCore/Store/{TicklerDatabase,ReminderStore,ChangeNotifier}.swift`, tests `ReminderStoreTests.swift`.

**Produces:**
- `struct Reminder: Codable, Identifiable, Hashable, FetchableRecord, PersistableRecord` with the spec columns; `enum Status: String { open, done, deleted }`, `enum Source: String { claude, human }`.
- `struct ReminderLink` (`reminderId`, `position`, `url`, `kind: LinkKind`, `label`).
- `enum ReminderID { static func generate() -> String }` (6 chars from `abcdefghjkmnpqrstuvwxyz23456789`).
- `final class TicklerDatabase { init(path: String) throws; static func defaultPath() -> String; let pool: DatabasePool }` running the migrator.
- `final class ReminderStore { init(database:, now: @escaping () -> Date = Date.init) }` with `add(_ draft: ReminderDraft) throws -> Reminder`, `get(_ id:) throws -> Reminder?`, `links(for:)`, `list(_ filter: ReminderFilter) throws -> [Reminder]`, `markDone(_:)`, `reschedule(_:to:)`, `update(_:title:notes:)`, `delete(_:)`, `markNotified(_:at:)`, `projects() -> [String]`.
- `ReminderFilter { due: DueScope (.today, .week, .overdue, .all), status, project: String? }`; `.today` = due before end of today, overdue included.
- `enum ChangeNotifier { static func post(); static func observe(_ handler:) -> token }` on the Darwin center.

**Tests:** add then get round-trips; links rebuilt from notes plus explicit links; `reschedule` bumps count and keeps `originalDueAt`; `delete` is soft and hidden from `list`; `.today` includes yesterday's open one and excludes tomorrow's; `.week` bound at now + 7 days; project filter on last path component of `cwd`; done ones only with `status: .done`; two pools on one file both write (Review Focus). Commit `feat(core): add reminder store`.

### Task 3: Link extraction

**Files:** `Sources/TicklerCore/Links/LinkExtractor.swift`, tests.

**Produces:** `enum LinkKind: String, Codable { gitlabMR, jira, grafana, slack, githubPR, other }`; `enum LinkExtractor { static func extract(from text: String) -> [URL]; static func classify(_ url: URL) -> (LinkKind, String) }`.

**Tests (table):** GitLab MR `.../platform/prober/-/merge_requests/221` gives `(.gitlabMR, "prober !221")`; Jira `https://x.atlassian.net/browse/OPS-2204` gives `(.jira, "OPS-2204")`; Slack `https://acme.slack.com/archives/D05.../p179...` gives `(.slack, "Slack thread")`; GitHub PR `github.com/o/r/pull/12` gives `(.githubPR, "r #12")`; Grafana `/d/tempo-writes` gives `(.grafana, "tempo-writes")`; other keeps the host. Trailing `).,;:` stripped, dedup keeps first position. Commit `feat(core): extract and classify links`.

### Task 4: Date parsing

**Files:** `Sources/TicklerCore/Dates/{DateParser,DateGrammar,FrenchGrammar,EnglishGrammar,StrictDate,DueBucket}.swift`, tests.

**Produces:**
- `enum StrictDate { static func parse(_ s: String, calendar:) -> Date?; static func format(_ d: Date, calendar:) -> String }` (CLI format).
- `protocol DateGrammar { var language: String { get }; func parse(_ input: String, now: Date, calendar: Calendar) -> Date? }`.
- `struct DateParser { init(preferred: String, grammars: [DateGrammar] = [FrenchGrammar(), EnglishGrammar()]); func parse(_:now:calendar:) -> Date? }`: ISO first, preferred grammar, then others; rejects past.
- `enum DueBucket { overdue, today, tomorrow, later }` with `static func of(_ due: Date, now:, calendar:)`.
- `enum RelativeTime { static func describe(_ due: Date, now: Date, locale: Locale) -> String }` ("in 15 min", "1 h 15 ago").

**Tests (frozen now = Thu 2026-10-01 10:45 Europe/Paris):** `demain 9h30` gives 10-02 09:30; `lundi 10h` gives 10-05 10:00; `jeudi 14h` gives 10-08 14:00 (today's weekday means next week); `dans 2h` gives 12:45; `dans 30 min` gives 11:15; `15:00` gives today 15:00; `9h` gives tomorrow 09:00 (Review Focus); `tomorrow 9:30am`, `monday 10am`, `in 2h`, `3pm`; ISO `2026-10-06 10:00`; garbage returns nil; `2026-09-01 10:00` (past) returns nil; case and accents (`Demain`, `aujourd'hui 18h`). Buckets and relative strings for a few offsets. Commit `feat(core): parse natural language dates`.

### Task 5: Notification and calendar planners

**Files:** `Sources/TicklerCore/Planning/{NotificationPlanner,CalendarPlanner,NotificationCategory}.swift`, tests.

**Produces:**
- `struct PlannedNotification: Hashable { id: String (reminderId@epoch), reminderId, fireAt, title, subtitle, body, category: NotificationCategory }`.
- `enum NotificationCategory: String, CaseIterable` with 6 cases `reminder.<ticket|none>.<slack|link|none>`, `static func for(links:)`, `var hasTicket/hasSlack/hasLink`.
- `enum NotificationPlanner { static func plan(reminders: [Reminder], links: [String: [ReminderLink]], pendingIds: Set<String>, now: Date, limit: Int = 64) -> (add: [PlannedNotification], remove: [String]); static func catchUp(reminders:, pendingIds:, now:) -> CatchUp }` where `CatchUp = .none | .individual([Reminder]) | .summary(count: Int)`.
- `struct CalendarMapping { reminderId, eventIdentifier, calendarId, syncedHash }`; `enum CalendarPlanner { static func contentHash(_ r: Reminder, links:) -> String; static func plan(reminders:, links:, mappings: [CalendarMapping], calendarId: String, now: Date) -> [CalendarAction] }` with `CalendarAction = .create(Reminder) | .update(Reminder, eventIdentifier) | .delete(eventIdentifier, reminderId)`.

**Tests:** future open reminders become requests, past ones do not; limit 64 keeps the nearest; a rescheduled reminder removes old id and adds new; done ones removed; catch-up skips notified and pending ones (Review Focus), 1 to 3 individual, 4+ summary; categories from links; calendar: create when no mapping, nothing when hash equal, update when hash differs, delete for done or out of window, delete plus create when mapping is on another calendar. Commit `feat(core): add notification and calendar planners`.

### Task 6: Session resumer

**Files:** `Sources/TicklerCore/Resume/{SessionRegistry,ProcessInspector,TerminalDriver,WezTermDriver,SessionResumer}.swift`, tests.

**Produces:**
- `protocol ProcessInspecting { func isAlive(_ pid: Int32) -> Bool; func tty(of pid: Int32) -> String?; func findPid(matching: (String) -> Bool) -> Int32? }` with `SystemProcessInspector` (libproc, sysctl).
- `struct SessionRegistry { init(directory: URL); func live(sessionId:, inspector:) -> (pid: Int32, cwd: String)? }`.
- `protocol TerminalDriver { func paneId(forTTY: String) throws -> String?; func activate(paneId:) throws; func spawn(cwd: String, command: [String]) throws -> String; func isRunning() -> Bool }`; `WezTermDriver(binary: URL)` runs `wezterm cli ...`, decodes `list --format json`.
- `struct SessionResumer { init(registry:, inspector:, driver:); func resume(sessionId: String, fallbackCwd: String?) throws -> ResumeOutcome }` with `.focused(paneId) | .spawned(paneId)` and `ResumeError.notRunningNoFolder | .folderMissing | .notInWezTerm | .terminal(String)`.
- `static func resumeCommand(sessionId:) -> [String]` (env scrubbing, `zsh -lic`).
- `WezTermDriver.resolveBinary(configured: String?) -> URL?`.

**Tests:** registry match plus alive pid gives focus of the pane matching the tty; stale registry file (dead pid) spawns in `fallbackCwd`; ps fallback match; no folder gives `notRunningNoFolder`; missing folder gives `folderMissing`; alive but no pane gives `notInWezTerm`; command scrubs `CLAUDECODE` and friends. Commit `feat(core): resume Claude sessions in WezTerm`.
